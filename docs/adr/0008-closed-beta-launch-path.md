# 0008. Closed beta before public launch

- **Status:** Accepted
- **Date:** 2026-08-21

## Context

Problem-solution fit is unproven, and the first public reviews of an unknown app carry outsized ASO damage. A landing-page/waitlist phase produces weak signal for utility apps (signups ≠ usage) while delaying real behavioral data.

## Decision

Build the MVP (~6 weeks), then:

1. **Play internal testing** track for smoke releases.
2. **Closed beta with 20–50 freelancers** recruited from communities (Discord/Slack/WA groups), with an in-app feedback channel.
3. **2–4 weeks of iteration** on beta feedback.
4. **Public launch.**

No landing page, no waitlist phase.

## Consequences

- Slower time-to-public in exchange for protected ratings and real usage signal.
- The beta explicitly observes which direction (I owe vs Waiting for) dominates usage — that ratio sharpens the wedge and post-beta positioning.
- Requires a GitHub remote + Play Console access before beta starts.
